# Late Deliveries, Low Stars (Team 2, Pandas Pioneers)
Olist e-commerce operations analysis and dashboard.

## Data
Download "Brazilian E-Commerce Public Dataset by Olist" from Kaggle and put the 9 CSV files in data/.
The notebook saves cleaned files (orders_clean.csv.gz, seller_orders_clean.csv.gz) into data/.

## Run
- Notebook: open notebook/olist_analysis.ipynb and Run All.
- App: pip install -r app/requirements.txt, then streamlit run app/app.py
